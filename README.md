# 坦克大战

一个使用HTML5 Canvas开发的经典坦克大战游戏。

## 游戏特性

- 🎮 经典坦克大战玩法
- 🎯 方向键控制移动，空格键射击
- 💥 可破坏的砖墙和不可破坏的钢墙
- 🏆 分数系统和关卡系统
- ❤️ 生命系统
- 🎨 爆炸动画效果

## 如何运行

1. 直接在浏览器中打开 `index.html` 文件即可开始游戏

## 游戏操作

- **方向键 ↑↓←→**: 控制坦克移动
- **空格键**: 发射子弹
- **R键**: 重新开始游戏

## 游戏规则

- 保护底部的基地（红色标记）不被摧毁
- 消灭所有敌方坦克进入下一关
- 砖墙可以被子弹摧毁，钢墙无法摧毁
- 玩家有3条生命，被击中后会减少生命

## 技术栈

- HTML5
- CSS3
- JavaScript (Canvas API)
